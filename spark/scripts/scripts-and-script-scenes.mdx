## Scripts, script scenes and 3D scenes

Spark uses three words that sound alike. Each one names a different thing.

| Term | What it is |
|------|------------|
| Script | A screenplay in a production. Spark keeps it in Fountain format. |
| Script scene | One scene heading in the script, such as `INT. STUDIO - DAY`. |
| 3D scene | A set you build for a script scene. A script scene can hold several. |
| Scene editor | The **3D Scene** tab, where you build a 3D scene. |

Scene headings don't make 3D scenes on their own. Each script scene starts with none, and you add each 3D scene with **Create a new 3D scene**. Spark names it after the script scene.

## Add a script

On the production's **Scripts** tab, click **Add a Script**. Pick one of three starts.

| Choice | What it does |
|--------|--------------|
| **Upload** | Brings in a `.fountain`, `.txt`, `.fdx` or `.pdf` file. |
| **Use default script** | Adds the Fountain Syntax Guide, a sample script that shows every screenplay element. |
| **Skip to 3D scene** | Adds an empty script with one 3D scene, and opens that scene in the scene editor. |

## Jump to a script scene

Click a heading under **Script scenes**. Spark highlights that scene in the script, and the 3D scene list shows its 3D scenes. To find a heading in a long script, type part of it into **Search**.

## Switch between scripts

In the breadcrumb at the top, click the arrow beside the script's name, then pick another script. The **Scripts** tab also lists every script, with how many 3D scenes each holds.

## Rename or delete a script

Both live on the script's row on the **Scripts** tab. Click **⋯** at the end of the row.

- To rename, click **Settings**, change **Title**, then click **Save**. The gear on the script page opens the same window.
- To delete, click **Delete**, then **Delete** again to confirm.

<Warning>
  Deleting a script also deletes its 3D scenes and cameras, for good.
</Warning>
