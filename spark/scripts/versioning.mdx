Every edit saves as a draft version that only you see. The team reads the published version until you publish your draft.

**Publish changes** appears when you have a draft to publish. **Import Newer Version** brings in a new draft from a file. The newest version is at the top. **Imported** marks a version that came from a file, and **Current Version** marks the published one that everyone reads.

## The Versioning column

Switch the script to **Edit** to see it, with **Ctrl+E** (**Cmd+E** on a Mac). It lists every version of the script, newest first.

The Current Version is what everyone reads. 3D scenes, lists and downloads use it too.

## Publish your edits

<Steps>
  <Step title="Open your draft">
    In View mode, a draft shows as **Unpublished edits**. Click **Review & publish** to open it in Edit mode.

    <img
      src="/images/spark/scripts/unpublished-edits.png"
      alt="The top of a script in View mode. Box 1 is on Unpublished edits and 2 on Review and publish."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '520px' }}
    />

    <div className="key cols-2 left">

    1. **Unpublished edits**
    2. **Review & publish**

    </div>
  </Step>
  <Step title="Publish it">
    Click **Publish changes**, then **Publish changes** again to confirm.

    <img
      src="/images/spark/scripts/publish-changes-button.png"
      alt="The top of the Versioning column in Edit mode, with a box on Publish changes."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '580px' }}
    />

    <img
      src="/images/spark/scripts/publish-changes.png"
      alt="The Publish your edits window, with Keep editing and a box on Publish changes."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '440px' }}
    />
  </Step>
</Steps>

Your draft becomes the Current Version. New scene headings join **Script scenes**, and the earlier versions stay in the list.

## Import a newer version

Use this when a new draft arrives from your screenwriting app. It adds the file as a new version, so the script keeps its history.

<Steps>
  <Step title="Open the Versioning column">
    Switch the script to **Edit**, then click **Import Newer Version**.

    <img
      src="/images/spark/scripts/import-newer-version.png"
      alt="The top of the Versioning column. Box 1 is on the Edit switch and 2 on Import Newer Version."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '436px' }}
    />

    <div className="key cols-2 left">

    1. **Edit**
    2. **Import Newer Version**

    </div>
  </Step>
  <Step title="Choose the file">
    Drag in a `.fountain`, `.txt`, `.fdx` or `.pdf` file, or click **Choose from browser**. Check the preview.

    <img
      src="/images/spark/scripts/import-choose-file.png"
      alt="The Import Version window, with a box on Choose from browser."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '420px' }}
    />
  </Step>
  <Step title="Import and publish">
    Click **Import**. The file becomes a draft tagged **Imported**. Publish it as you would any edit.

    <img
      src="/images/spark/scripts/import-button.png"
      alt="The top of the Import Version window for rooftop-test-v2, with a box on Import."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '560px' }}
    />
  </Step>
</Steps>

## Go back to an earlier version

<Steps>
  <Step title="Open the version">
    In the **Versioning** column, click the version you want. **Version History** shows it beside the version before it.

    <img
      src="/images/spark/scripts/version-card.png"
      alt="The Versioning column with four versions, and a box on the 6:10 PM version."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '300px' }}
    />
  </Step>
  <Step title="Revert to it">
    Click **Revert to this version**, then **Revert**. Spark adds it as a new draft.

    <img
      src="/images/spark/scripts/revert-confirm.png"
      alt="The Revert to version 1 window, with Cancel and a box on Revert."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '440px' }}
    />
  </Step>
  <Step title="Publish it">
    Click **Publish changes** to make it the Current Version.

    <img
      src="/images/spark/scripts/publish-changes-button.png"
      alt="The top of the Versioning column in Edit mode, with a box on Publish changes."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '580px' }}
    />
  </Step>
</Steps>

<img
  src="/images/spark/scripts/version-history.png"
  alt="The Version History window. Box 1 is on Revert to this version, and 2 on lines shown in red because the selected version doesn't have them."
  style={{ borderRadius: '0.5rem' }}
/>

<div className="key cols-2">

1. **Revert to this version**
2. Lines only in the version before

</div>

Lines in red are in the version before it, but not in the one you picked.

Nothing is lost when you revert. Every version stays in the list, so you can return to any of them later.
