The script page has two modes. View shows the published script as a formatted screenplay. Edit opens its text, so you can write and format it.

**Add elements** opens a panel of screenplay elements to insert. **Save pattern** keeps your own text for reuse. You type into the script itself. For the **Versioning** column, see [Drafts and versions](/spark/scripts/versioning).

## View and Edit

Click the switch, or press **Ctrl+E** (**Cmd+E** on a Mac). In Edit mode, the **Versioning** column takes the place of the 3D scene list.

Spark saves your typing as you go, as a draft that only you see. Others see it once you publish it. See [Publish your edits](/spark/scripts/versioning#publish-your-edits).

<Tip>
  The **Light** and **Dark** switch changes only the script page, from a dark page to white paper.
</Tip>

## Write scene headings

Start a line with `INT.`, `EXT.`, `EST.`, `INT./EXT.` or `I/E.`, then the place and the time of day.

```text Scene headings
INT. STUDIO - DAY

EXT. ROOFTOP - NIGHT

.FLASHBACK
```

A line that starts with a period counts as a heading too, as `.FLASHBACK` does here. A new heading joins **Script scenes** once you publish.

## Format screenplay elements

Spark writes scripts in [Fountain](https://fountain.io), plain text that formats itself. Click **Add elements** to insert an element without typing its syntax.

<Steps titleSize="h3">
  <Step title="Place the cursor">
    Click in the script where the element should go.
  </Step>
  <Step title="Insert the element">
    Click **Add elements**, then click an element. Spark inserts sample text at the cursor.

    <img
      src="/images/spark/scripts/insert-element.png"
      alt="The script in Edit mode with the elements panel open. Box 1 is on Add elements, 2 on Scene Heading and 3 on the sample heading it inserted."
      style={{ borderRadius: '0.5rem' }}
    />

    <div className="key cols-3">

    1. **Add elements**
    2. Element
    3. Sample text

    </div>
  </Step>
  <Step title="Replace the sample">
    Type over the sample text with your own.

    <img
      src="/images/spark/scripts/replace-sample.png"
      alt="The script in Edit mode, with a box on the new lines INT. ELEVATOR - NIGHT and Maya rides down alone."
      style={{ borderRadius: '0.5rem' }}
    />
  </Step>
</Steps>

| Element | What it is | Sample Spark inserts |
|---------|------------|----------------------|
| Title Block | Title page details | `Title: My Script` |
| Scene Heading | Place and time | `INT. LOCATION - DAY` |
| Action | What happens on screen | `Action description.` |
| Dialogue | A character's name, then their line | `CHARACTER NAME` |
| Parenthetical | How a line is said, between name and line | `(quietly)` |
| Transition | A cut to the next scene, set to the right | `CUT TO:` |
| Centered | Text set in the middle, such as an act break | `>THE END<` |
| Section | An act or section marker that doesn't print | `# ACT ONE` |
| Note | A comment that doesn't print | `[[Director note]]` |

To save your own pattern, select the text, click **Save pattern**, name it, then click **Save**. It appears under **Custom** in **Add elements**.
