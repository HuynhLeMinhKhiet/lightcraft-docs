The Asset Library holds every file a production can use: locations, objects and audio. Open it from the **Asset Library** tab, or from a **+** in the Outliner, which opens it on that category.

## Categories and default assets

| Category | Files | Subcategories |
|----------|-------|---------------|
| **Locations** | `.ply` `.splat` `.spz` `.usd` `.usdc` `.usda` `.usdz` | Interior, Exterior |
| **Objects** | `.usd` `.usdc` `.usda` `.usdz` | Character, Vehicle, Prop, Primitive |
| **Audio** | `.mp3` `.wav` `.ogg` `.m4a` `.aac` `.flac` | — |

Default assets come with every production, such as the Opulent Hall location and the Motorcycle object. Use them to try Spark before you upload anything.

## Add a file

<Steps titleSize="h3">
  <Step title="Click Add to Library">
    From **All assets**, Spark asks what kind of file it is. Pick **Location**, **Object** or **Audio**. Inside a category, Spark skips this step.

    <img
      src="/images/spark/scene-editor/select-category.png"
      alt="The Select Category window, asking what kind of file you are uploading, with a box on the Location, Object and Audio cards and the file types for each."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '620px' }}
    />
  </Step>
  <Step title="Choose the file">
    Drag it in, or click **Choose from browser**. A preview shows on the left.

    <img
      src="/images/spark/scene-editor/choose-file.png"
      alt="The upload area, Drag and drop or Choose from browser, with a box on Choose from browser and the file types listed below."
      style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '560px' }}
    />
  </Step>
  <Step title="Fill in the settings">
    Name the file and pick its subcategory. Locations and objects also ask how to turn and size them. See [Locations](/spark/scene-editor/locations#location-settings) and [Objects](/spark/scene-editor/objects#prepare-usd-objects).

    <img
      src="/images/spark/scene-editor/fill-in-settings.png"
      alt="The Location Settings window. Box 1 is on the settings column with Subcategory, Location name, Tags and Transformation, and 2 on Add to Library."
      style={{ borderRadius: '0.5rem' }}
    />

    <div className="key cols-2">

    1. Settings
    2. **Add to Library**

    </div>
  </Step>
  <Step title="Click Add to Library">
    The upload's progress shows at the top of the page. The file then shows in its category.
  </Step>
</Steps>

On a file's card in the Asset Library tab, **⋯** holds **Edit Metadata**, **Download** and **Delete**.

## Upload limits

You add files only by uploading them to the library. The old **Load Locally** option is gone.

- One file can be up to 1 GB. Spark refuses an empty file.
- **Add Multiple** takes up to 50 files of one kind. It skips duplicates, and refuses a file of the wrong kind.
