---
title: "Bring in an Unreal scene"
description: "Export a scene from Unreal Engine as a Gaussian splat and a USD file for the Spark web app."
---

Export a scene from Unreal Engine as a Gaussian splat for the environment and a USD file for foreground meshes. Then bring both into the Spark web app.

## 1. Separate foreground elements

<video src="/images/spark/create-mesh-layer.mp4" controls style={{ borderRadius: '0.5rem' }} />

<video src="/images/spark/add-objects.mp4" controls style={{ borderRadius: '0.5rem' }} />

Decide which objects in your scene stay as mesh geometry. Keep anything with fine detail the splat might miss, and anything you may shoot through, such as railings, stairs and furniture.

1. In the Unreal Editor, open the **Layers** panel.
2. Add a new layer and name it **Mesh**.
3. Drag the foreground elements you want to keep as mesh geometry into this layer, such as tables, chairs, railings and staircases.

## 2. Add scene locators

<video src="/images/spark/add-scene-locator.mp4" controls style={{ borderRadius: '0.5rem' }} />

Scene locators mark where you place actors, and the spots you jump to during previs.

1. Add an empty actor to the scene.
2. Name it in the form `Scene_Lock_01`, replacing `01` with a descriptive name or number.
3. Position it where you want the first locator.
4. **Alt\+drag** the actor to duplicate it and create additional locators at other key positions.

<video src="/images/spark/duplicate-scene-locator.mp4" controls style={{ borderRadius: '0.5rem' }} />

5. Add the scene locators to your **Mesh** layer so they export with the foreground elements.

<video src="/images/spark/create-mesh-layer.mp4" controls style={{ borderRadius: '0.5rem' }} />

## 3. Install the USD exporter plugin

<video src="/images/spark/install-usd-plugin.mp4" controls style={{ borderRadius: '0.5rem' }} />

1. Open **Edit \> Plugins**.
2. Search for **USD Importer**, which handles both import and export.
3. Turn on the plugin.
4. Restart Unreal Engine.

## 4. Export as USD

<video src="/images/spark/export-usd.mp4" controls style={{ borderRadius: '0.5rem' }} />

1. Select the **Mesh** layer (double-click it to select all its contents, including the scene locators).
2. Click **File \> Export Selected**.
3. Choose **USD** from the file type dropdown.
4. In the USD export settings, turn on **Bake Materials**.

<video src="/images/spark/bake-materials.mp4" controls style={{ borderRadius: '0.5rem' }} />

5. Expand the material settings menus and remove any generated elements you don't need.
6. Click **Export**.

## 5. Render a panoramic 360 image

Render a single panoramic frame from Unreal Engine to use as the source for your Gaussian splat.

1. Open **Edit \> Plugins** and turn on **Additional Render Passes**.
2. Add a **Camera** actor to the scene and position it in the center of your environment.

<video src="/images/spark/create-camera.mp4" controls style={{ borderRadius: '0.5rem' }} />

3. Open the **Sequencer**, drag your camera in, and set the in and out points so it renders a single frame.

<video src="/images/spark/sequencer-single-frame.mp4" controls style={{ borderRadius: '0.5rem' }} />

4. Open the **Media Render Queue** for the sequence.
5. In the render settings, delete the default **Deferred Rendering** pass.

<video src="/images/spark/media-render-queue.mp4" controls style={{ borderRadius: '0.5rem' }} />

6. Open **Settings \> Panoramic Rendering** and turn on **Allocate History Per Pane**. Without it, the render comes out too dark.

<video src="/images/spark/allocate-history.mp4" controls style={{ borderRadius: '0.5rem' }} />

7. Add any anti-aliasing settings you need.

<video src="/images/spark/antialiasing-info.mp4" controls style={{ borderRadius: '0.5rem' }} />

8. Set the output resolution to **4096 x 2048** (2:1 aspect ratio).

<video src="/images/spark/render-output.mp4" controls style={{ borderRadius: '0.5rem' }} />

9. Render the frame.

## 6. Convert to a Gaussian splat with World Labs

1. Open [World Labs](https://www.worldlabs.ai/) and choose **2D Input**.

<video src="/images/spark/wl-import-image.mp4" controls style={{ borderRadius: '0.5rem' }} />

2. Drag your panoramic render into World Labs.
3. World Labs makes a Gaussian splat from the image and keeps the lighting from your Unreal scene.
4. Download the result as a **PLY** file.

<video src="/images/spark/wl-download.mp4" controls style={{ borderRadius: '0.5rem' }} />

## 7. Import into the Spark web app

1. In the Spark web app, click **Add** and choose **Location**.
2. Upload your PLY Gaussian splat file. This becomes the environment background with baked lighting.

<video src="/images/spark/add-gaussian.mp4" controls style={{ borderRadius: '0.5rem' }} />

3. Click **Add** again and choose **Object**.

<video src="/images/spark/import-usd.mp4" controls style={{ borderRadius: '0.5rem' }} />

4. Import your USD or USDZ file with the foreground elements.

The final scene combines mesh detail for foreground elements with a Gaussian splat background that preserves the original Unreal Engine lighting.

<video src="/images/spark/combo-results.mp4" controls style={{ borderRadius: '0.5rem' }} />
