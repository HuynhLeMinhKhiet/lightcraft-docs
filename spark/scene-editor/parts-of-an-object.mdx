A USD object built from several meshes has parts, such as the pole and shade of a lamp. You can move or hide one part without changing the rest of the object.

## What a part is

Spark counts each mesh in the file as a part. An object with two or more parts gets a chevron on its Outliner row, and a **Parts** row under it. A part gets its own row there once you select it.

## Select a part

Select the object, then double-click the part in the 3D canvas. The part turns orange, and the gizmo moves to it.

<img
  src="/images/spark/scene-editor/part-selected.jpg"
  alt="The Pole part of the desk lamp selected in orange. Box 1 is on the pole, 2 on the path P5 desk lamp mesh, DeskLamp, Pole at the bottom of the canvas, 3 on the Parts row and 4 on the Pole row."
  style={{ borderRadius: '0.5rem' }}
/>

<div className="key cols-2">

1. Selected part
2. Path to the part, with an eye
3. **Parts** row
4. Part row

</div>

The eye on the path hides the part. **Shift**-click adds a part, and **Esc** deselects.

**Object Properties** still shows the whole object while a part is selected.

### Find a part

Click **Find a part** (the magnifier) on the **Parts** row. Type to filter the list, then click a part to select it.

  src="/images/spark/scene-editor/part-search.png"

## Move or hide a part

- **Move:** drag the gizmo. Only that part moves, and its row is marked **moved**.
- **Hide:** hover the part's row, then click the eye. The part leaves the canvas, and the row turns dim.

## Select several parts

Select a part, then **Shift**-click another. The Properties panel shows **Parts** with a count, such as **2 parts selected**.

<img
  src="/images/spark/scene-editor/parts-selected-several.png"
  alt="The Parts panel: 2 parts selected. Box 1 is on Hide all, 2 on Reset transforms and 3 on Remove. Below are one line each for Pole and Shade, and a hint about Shift-click."
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '290px' }}
/>

<div className="key cols-3 left">

1. **Hide all**
2. **Reset transforms**
3. **Remove**

</div>

**Hide all** hides every selected part, and then reads **Show all**. **Reset transforms** puts every moved part back, and is greyed out when no part has moved. **Remove** clears the changes on every selected part.

Drag the gizmo to move the parts together. To rotate or scale, select a single part.

## Put a part back

- **Reset transform** on the part's row puts it back where the file has it, and clears **moved**.
- The trash on the row opens **Remove Overrides**. Click **Remove** to clear every change. The part returns to its place in the file, shows again, and leaves the **Parts** list.

<img
  src="/images/spark/scene-editor/part-remove-overrides.png"
  alt="The Remove Overrides window. It says the mesh stays in the scene and returns to its original position and visibility, and to use the eye icon to remove it from view. A box is on Remove."
  style={{ borderRadius: '0.5rem', width: '100%', maxWidth: '520px' }}
/>

A camera can follow one part. If one follows the part you clear with **Remove Overrides**, it follows the whole object instead, from where it is now. See [Setups and cameras](/spark/scene-editor/setups-and-cameras).
