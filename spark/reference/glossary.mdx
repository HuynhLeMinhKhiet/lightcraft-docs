---
title: 'Glossary'
description: 'What the words in Spark and in these docs mean.'
---

Each term links to the page that covers it.

| Term | Meaning |
|------|---------|
| [3D scene](/spark/scene-editor/3d-scenes) | A set you build for one script scene, with its own location, objects and cameras. |
| [Admin](/spark/organizations-productions/members-and-seats) | A member who can open every production in the organization. |
| [Asset Library](/spark/scene-editor/asset-library) | Every file a production can use: locations, objects and audio. |
| [Base Setup](/spark/setups-cameras/setups) | The setup every 3D scene starts with. |
| [Camera](/spark/setups-cameras/cameras) | A view inside one setup, with its own lens and move. |
| [CG Take](/spark/gallery/gallery#takes-and-cg-takes) | One camera's move through a 3D scene, rendered in the browser. |
| [Direct Drive](/spark/spark-ios/live-camera-sharing) | The browser's name for live camera sharing from an iPhone. |
| [Edit](/spark/editing/editor) | One cut of takes and sound, made in the Editor. |
| [Editor](/spark/editing/editor) | The tab where you cut takes into an edit. |
| [Gallery](/spark/gallery/gallery) | Every take in a production. |
| [Gaussian splat](/spark/scene-editor/locations) | A 3D scan of a real or generated place, the usual kind of location. |
| [Jetset](/spark/export-jetset/shoot-with-jetset) | The app that takes a 3D scene onto a set with a cinema camera. |
| [List](/spark/gallery/gallery#create-and-edit-a-list) | A collection of CG Takes and Takes from anywhere in the script. |
| [Location](/spark/scene-editor/locations) | The world a 3D scene takes place in. Each 3D scene holds one. |
| [Locator](/spark/scene-editor/audio-locators-and-rulers) | A marked point in a 3D scene, saved in the USD file on export. |
| [Object](/spark/scene-editor/objects) | A USD model you place in a location, such as a prop, vehicle or character. |
| [Organization](/spark/organizations-productions/organizations) | Your team's space in Spark, with its members, billing and productions. |
| [Outliner](/spark/scene-editor/scene-editor#outliner) | The panel that lists everything in a 3D scene. |
| [Part](/spark/scene-editor/parts-of-an-object) | One mesh of a USD object, which you can move or hide alone. |
| [Production](/spark/organizations-productions/productions) | One film, episode or commercial, with its scripts, assets, takes and edits. |
| [Scene editor](/spark/scene-editor/scene-editor) | The **3D Scene** tab, where you build a 3D scene. |
| [Script scene](/spark/scripts/scripts-and-script-scenes) | One scene heading in a script. |
| [Setup](/spark/setups-cameras/setups) | One arrangement of a 3D scene, with its own cameras. |
| [Spark Desktop](/spark/gallery/spark-desktop) | The computer app that moves takes off the iPhone. It installs as **Spark Atlas**. |
| [Spark iOS app](/spark/spark-ios/spark-ios-app) | The iPhone and iPad app you shoot takes with. |
| [Spark web app](/spark/get-started/install-and-sign-in) | Spark in Google Chrome, where you plan, review and edit. |
| [Take](/spark/gallery/gallery#takes-and-cg-takes) | A recording from the Spark iOS app. |
| [Timeline](/spark/setups-cameras/timeline-and-animation) | The panel under the 3D canvas, with a 3D scene's clips and keyframes. |
| [Title](/spark/organizations-productions/members-and-seats) | A member's job name. It doesn't change what they can open. |
| [Versioning](/spark/scripts/versioning) | The column that lists every version of a script. |
