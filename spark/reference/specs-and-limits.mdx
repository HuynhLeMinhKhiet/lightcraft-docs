## Supported file formats

| Asset | File types | Page |
|-------|------------|------|
| Location | `.ply` `.splat` `.spz` `.usd` `.usdc` `.usda` `.usdz` | [Locations](/spark/scene-editor/locations) |
| Collision mesh | `.glb` | [Locations](/spark/scene-editor/locations) |
| Object | `.usd` `.usdc` `.usda` `.usdz` | [Objects](/spark/scene-editor/objects) |
| Audio | `.mp3` `.wav` `.ogg` `.m4a` `.aac` `.flac` | [Audio, locators and rulers](/spark/scene-editor/audio-locators-and-rulers) |
| Script | `.fountain` `.txt` `.fdx` `.pdf` | [Scripts and script scenes](/spark/scripts/scripts-and-script-scenes) |

## Size limits

| Item | Limit | Page |
|------|-------|------|
| One uploaded file | 1 GB | [Asset Library](/spark/scene-editor/asset-library#upload-limits) |
| **Add Multiple** | 50 files of one kind | [Asset Library](/spark/scene-editor/asset-library#upload-limits) |
| Production image | Square, up to 10 MB | [Productions](/spark/organizations-productions/productions) |
| Splats in the Spark iOS app | About 5 million per 3D scene | [Spark iOS app](/spark/spark-ios/spark-ios-app) |

## Frame rates

| Where | Frame rate | Page |
|-------|------------|------|
| Production | 24 fps or 25 fps, set when you create it | [Productions](/spark/organizations-productions/productions) |
| New edit | 24 fps, which you can change in **New export** | [Editor](/spark/editing/editor) |

## Export formats

| Export | Format | Page |
|--------|--------|------|
| Gallery download | One zip, with each take's files in folders | [Review and share takes](/spark/gallery/gallery#download-takes) |
| Edit | MP4, H.264 video with AAC sound | [Editor](/spark/editing/editor) |
| 3D scene | `.usdz`, or a QR code for Jetset that expires in 5 minutes | [Shoot with Jetset](/spark/export-jetset/shoot-with-jetset) |
