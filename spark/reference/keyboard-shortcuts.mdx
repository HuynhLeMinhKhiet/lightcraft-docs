---
title: 'Keyboard shortcuts'
description: 'Every keyboard shortcut in the script page, the scene editor, the Timeline and the Editor.'
---

On a Mac, press **Cmd** wherever this page says **Ctrl**. In the scene editor, the keyboard button in the canvas toolbar shows the same list.

## Script page

| Key | Does |
|-----|------|
| **Ctrl+E** | Switch between View and Edit |

## Scene editor

| Key | Does |
|-----|------|
| Drag | Look around |
| **W**, **A**, **S**, **D** | Move forward, left, back or right |
| **Q**, **E** | Move down or up |
| Hold **Shift** | Move faster |
| **Alt**+drag | Orbit around the point in view |
| Scroll | Move forward or back |
| **Shift+F** | Enlarge or shrink the camera preview |
| **Ctrl+1** | Position gizmo |
| **Ctrl+2** | Rotate gizmo |
| **Ctrl+3** | Scale gizmo, objects only |
| Double-click | Select the part under the cursor |
| **Alt+↑**, **Alt+↓** | With a part selected, step out to its group or back in |
| **Esc** | Exit full screen or placement, then clear the selection |

In **Top-Down View**, **W**, **A**, **S** and **D** move the view, middle-drag pans, and scroll zooms.

## Timeline

| Key | Does |
|-----|------|
| **Space** | Play or pause |
| **←**, **→** | One frame back or forward |
| **Shift+←**, **Shift+→** | 1 second back or forward |
| **Shift+↑** | Jump to the start |
| **Shift+↓** | Jump to the end, or the selected camera's last keyframe |
| **Alt+↑**, **Alt+↓** | Zoom in or out, unless a part is selected |
| **Ctrl**+scroll | Zoom at the cursor |
| **Shift**+scroll | Scroll sideways |
| **Shift**+drag | Scrub without frame snapping |

## Undo, copy and delete

| Key | Does |
|-----|------|
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** | Redo |
| **Ctrl+C**, **Ctrl+V** | Copy or paste the selection |
| **Delete** | Delete the selected keyframes or clips |
| **Shift**+click | Add to the selection |

## Editor

| Key | Does |
|-----|------|
| **Space** | Play or pause |
| **←**, **→** | One frame back or forward |
| **Shift+←**, **Shift+→** | 1 second back or forward |
| **Shift+↑** | Jump to the start |
| **Shift+↓** | Jump to the end of the last clip |
| **↑**, **↓** | Previous or next take in the left column |
| **I**, **O** | Mark in or mark out |
| **Alt+X** | Clear the marks |
| **V** | Insert |
| **B** | Overwrite |
| **F** | Open the selected clip's source |
| **Ctrl+K** | Split the clip at the playhead |
| **Q**, **W** | Trim the start or the end |
| **G** | Close a gap |
| **Delete** | Remove the selection. **Backspace** on a Mac |
| **Esc** | Clear the selection |
| **Shift+S** | Show or hide the clip viewer |
| **Shift+I** | Show or hide the inspector |
| **Ctrl+Z**, **Ctrl+Shift+Z** | Undo or redo |
| **Ctrl**+scroll | Zoom the timeline at the pointer |
